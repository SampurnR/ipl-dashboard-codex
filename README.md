# IPL Analytics

## What this is

IPL Analytics is a static dashboard and Python pipeline for exploring IPL match, team, and player metrics from Cricsheet ball-by-ball data. The pipeline cleans per-match CSVs, calculates summary metrics with pandas, and exports JSON for the dashboard.

## Quick start

Requires Python 3.14 and Node.js for the dashboard test suite. From the project root:

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install pandas
python scripts/download_data.py
python scripts/run_pipeline.py
python -m unittest discover -s tests
node --test tests/dashboard.test.mjs
python3 -m http.server --bind 127.0.0.1 --directory site
```

Open `http://localhost:8000` to view the local dashboard. The download script uses Cricsheet's IPL CSV2 archive and leaves existing match files in place.

Tests: CI runs both suites on every push and pull request.

## Project layout

- `data/raw/` Local Cricsheet match inputs and their source license; ignored by Git.
- `data/clean/` Generated normalized tables; ignored by Git.
- `scripts/` Python download, cleaning, metric, export, and pipeline stages.
- `scripts/config.py` Team aliases, sample thresholds, and shared pipeline settings.
- `scripts/download_data.py` Downloads and extracts Cricsheet per-match CSV files.
- `scripts/run_pipeline.py` Runs cleaning, metrics, and export with a raw-data integrity check.
- `site/` Static HTML, CSS, and vanilla JavaScript dashboard.
- `site/data/ipl_metrics.json` Bundled dashboard data generated by the pipeline.
- `site/fonts/` Bundled Barlow fonts and their license notice.
- `tests/` Python pipeline tests, dashboard helper tests, and small fixtures.
- `docs/` Build plan and pipeline architecture diagram.

## Data rules

- Legal balls exclude wides and no-balls. Batter balls faced exclude wides but count no-balls.
- Delivery metrics exclude super-over innings (`innings > 2`).
- Historical team aliases are canonicalized in `scripts/config.py`.
- Sample thresholds come from `scripts/config.py`: 60 balls across all seasons and 30 in one season; bowlers use legal balls bowled and batters use balls faced.
